# Python Quiz Game

A console quiz game built with Python using object-oriented programming.

## Features

- Questions stored in a JSON file, so they are easy to add or change
- Random questions in every game
- Input validation
- Leaderboard saved in a file

## How to run

1. Install Python 3
2. Run: `python quiz.py`

## What I learned

- Classes and objects (OOP)
- Reading and writing JSON files
- Error handling with try and except
- Using Git and GitHub
